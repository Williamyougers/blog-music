# 威灵T · Tracks & Notes

> 极简杂志风 · 个人音乐博客 · 单文件即开即用

## 特色

- 🎵 **作品库**：封面 + 标题 + 艺术家 + 流派 + 内嵌音频播放器
- ✎ **日志**：标题、正文、标签、自动折叠/展开
- 💾 **本地保存**：数据存浏览器 localStorage，关掉再开还在
- 📱 **完全响应式**：手机平板桌面都能用
- ⚡ **零依赖**：单个 HTML 文件，双击就开

## 用法

### 添加作品
点右上角「+ 添加作品」→ 填表单 → 保存
- **必填**：标题
- **选填**：艺术家、年份、流派、封面图 URL、音频 URL、说明
- 音频支持任意可直链播放的 mp3/wav/ogg
- 鼠标移到卡片上会出现 ▶ 播放按钮和 ✕ 删除按钮

### 写日志
点右上角「+ 写日志」→ 写完点发布
- **必填**：标题 + 正文
- **选填**：标签（用逗号分隔，如 `创作, 思考, 灵感`）
- 长文章会自动折叠，点「展开全文」看完整内容

### 删除
- 作品：悬停卡片 → 点右上角 ✕
- 日志：每条底部「删除」按钮
- 两者都会弹出确认对话框，避免误删

### 数据
- 所有数据存在本机浏览器 `localStorage`
- 换浏览器 / 清缓存会丢失
- 想多端同步？后续可以接 GitHub Gist / Supabase / 你自己的服务器

## 部署

零依赖单文件，部署超简单：

**最快：拖到 Vercel**
1. 打开 https://vercel.com/new
2. 把 `blog-music/` 文件夹拖进去
3. 30 秒后拿到公网 URL

**或者：GitHub Pages / Netlify / Cloudflare Pages**
原理一样，传文件 → 拿链接。

**仅本地：**
```bash
cd blog-music
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
